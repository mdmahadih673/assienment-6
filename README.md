#  FitLog — Workout Library

FitLog is a simple and responsive workout library web application built with Next.js. Users can browse different workouts, view workout details, add exercises to today's plan, and save workouts for later.

The main goal of this project is to practice Next.js, API integration, reusable components, responsive design, and state management.

##  Features

*  Browse all available workouts from the API
*  View detailed information about each workout
*  Add workouts to Today's Plan
*  Save workouts for later
*  Mark planned workouts as Done
*  Remove workouts from Today's Plan
*  Show total exercises, minutes, and calories
*  Toast notifications for user actions
*  Fully responsive for mobile, tablet, and desktop
*  Plan and Saved workouts are stored in localStorage
